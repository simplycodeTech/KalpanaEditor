Kalpna Editor

Works on any website — plain HTML, PHP, WordPress, Laravel, React, Vue… No build step needed.

1. HTML tag inside a normal form

<form method="post" action="save.php">
  <kalpna-text-editor name="content" placeholder="Write here…"></kalpna-text-editor>
  <button>Save</button>
</form>
(submitted HTML appears here)

2. Turn an existing <textarea> into the editor

<textarea id="body" name="body"><p>Existing content</p></textarea>
<script>
  KalpnaEditor.replace('#body', { language: 'mr', toolbar: 'basic' });
</script>
(textarea value appears here)

3. Create from JavaScript

KalpnaEditor.create('#holder', {
  value: '<h2>Report</h2>',
  uploadUrl: '/upload.php',          // optional image upload endpoint
  onChange: (html) => console.log(html)
}).then((editor) => editor.getHtml());
(live HTML)

4. Marathi & Hindi typing — namaskar → नमस्कार, aap kaise hain → आप कैसे हैं

<kalpna-text-editor name="content" typing-language="mr" language="mr"></kalpna-text-editor>

<!-- Hindi -->
<kalpna-text-editor name="content" typing-language="hi"></kalpna-text-editor>

<!-- or switch from JavaScript -->
editor.setTypingLanguage('mr');   // 'hi' = Hindi, 'en' = English

Type Suryakant Ubhe, namaskar, maharashtra shasan and press Space. For Hindi click हि हिंदी and type aap kaise hain. Use the [ English | मराठी | हिंदी ] switch on the toolbar, Alt+M, or choose a Devanagari font (Mangal, Mukta…).

5. Zero JavaScript: data attribute

<textarea name="notes" data-kalpna-editor='{"toolbar":"basic"}'></textarea>
