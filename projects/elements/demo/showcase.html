Add it to your website

1. Add one script tag

<script src="https://cdn.jsdelivr.net/npm/kalpna-editor@1/bundles/kalpna-editor.js"></script>

2. Put the editor in your form

<form method="post" action="save.php">
  <kalpna-text-editor name="content"
      typing-language="mr" upload-url="upload.php">
  </kalpna-text-editor>
  <button>Save</button>
</form>

…or upgrade an existing textarea

KalpnaEditor.replace('#body', { typingLanguage: 'mr' });
